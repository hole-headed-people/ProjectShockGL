# ProjectShockGL

Небольшой 3D-движок на C# и OpenGL с редактором уровней. Создаётся для игр от первого лица с исследованием пространства и логикой из взаимодействующих сущностей. Это авторский инструмент с развивающимся API; при разработке используется Codex.

**[Руководство по движку](docs/Guide.md)** — подключение своей игры, устройство систем, жизненный цикл, работа в редакторе, примеры кода и ограничения.

- ProjectShockGL — ядро, ресурсы, рендер, физика, UI и звук.
- ProjectShockGLEditor — редактор уровней и ассетов на ImGui.
- ProjectOxygenGL — необязательная библиотека игровой архитектуры.
- StarterContent — стартовые ресурсы; tests — проверки систем.

Нужны .NET SDK 8 и видеодрайвер с OpenGL 3.3. Основная проверенная среда — Windows.

```powershell
dotnet build ProjectShockGL.sln
```

Перед запуском задайте Content в DefaultSettings.ini, а в EditorSettings.ini укажите [Settings] DefaultPath к общему файлу своей игры. Порядок настройки — в [начале руководства](docs/Guide.md#start).
