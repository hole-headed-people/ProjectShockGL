# Задачи на будущее

## Виджет Text

- [ ] Добавить `FontSize` у виджета. Один растровый атлас должен работать с несколькими размерами текста. Измерение, перенос строк и выравнивание должны учитывать выбранный размер.
- [ ] Добавить начертания `Regular`, `Bold`, `Italic` и `BoldItalic` для всего виджета через отдельные TTF-файлы одной семьи.
- [ ] Добавить `AutoSize` с `MinFontSize` и `MaxFontSize`. Виджет выбирает самый крупный размер, при котором текст помещается в заданный `Rect` с учётом `WordWrap`. Если текст не помещается даже при минимальном размере, используется минимальный размер и обычное поведение `ClipToRect`.

## UI-атласы

- [x] Добавить 9-slice для `Image` с областями атласа, чтобы при изменении `Rect` углы сохраняли размер, края растягивались вдоль своих осей, а центр заполнял оставшееся место.

## Виджет Image

- [ ] Добавить отдельный режим `Filled`: `Horizontal`, `Vertical`, `Radial360` с `FillAmount` от 0 до 1, выбором начала заполнения и направлением `FillClockwise` для радиального режима. Изображение отсекается вместе с UV, без сжатия; поддержать отдельную текстуру, регион атласа и обрезку родителем. Добавить настройки в UI Editor и сохранение в UI JSON. `Simple`, `Sliced` и `Filled` остаются отдельными режимами: совмещение Filled с 9-slice не требуется.

## Отсечение геометрии и производительность

- [ ] После сборки большого этажа ProjectA измерить время кадра, CPU Update / Render, draw calls и треугольники без VSync в комнатах, длинных коридорах и местах с большим обзором. По результатам определить необходимость оптимизации.
- [ ] Добавить Frustum Culling обычных мешей по границам отрисовываемой геометрии и объёму текущей камеры. Учитывать отдельные камеры захвата, редактор и шейдерные деформации; не выключать игровую логику и физику отсечённых объектов.
- [ ] Пространственно разделить статичные батчи и группы instancing Details, чтобы отсекать невидимые части по их общим границам, сохранив батчинг, instancing и lightmap. При необходимости отдельно рассмотреть отсечение отдельных экземпляров Details.
- [ ] Если после Frustum Culling существенная нагрузка останется от помещений за стенами, рассмотреть Occlusion Culling или комнаты с порталами. Единый уровень сохраняем; выбор подхода — после замеров.
