# Задачи на будущее

## Виджет Text

- [ ] Добавить `FontSize` у виджета. Один растровый атлас должен работать с несколькими размерами текста. Измерение, перенос строк и выравнивание должны учитывать выбранный размер.
- [ ] Добавить начертания `Regular`, `Bold`, `Italic` и `BoldItalic` для всего виджета через отдельные TTF-файлы одной семьи.
- [ ] Добавить `AutoSize` с `MinFontSize` и `MaxFontSize`. Виджет выбирает самый крупный размер, при котором текст помещается в заданный `Rect` с учётом `WordWrap`. Если текст не помещается даже при минимальном размере, используется минимальный размер и обычное поведение `ClipToRect`.

## UI-атласы

- [ ] Добавить 9-slice для `Image` с областями атласа, чтобы при изменении `Rect` углы сохраняли размер, края растягивались вдоль своих осей, а центр заполнял оставшееся место.

## Звук и эффекты

- [ ] Добавить воспроизведение звука.
- [ ] Добавить систему частиц.

## Анимации

- [ ] Разобрать импорт из Blender и воспроизведение анимационных клипов. Анимации создаются в Blender.
- [ ] Отдельно рассмотреть скелетную анимацию и скиннинг, когда в игре появятся модели, которым они нужны.

## Освещение

- [ ] Рассмотреть динамические тени от направленных, точечных и прожекторных источников света.
- [ ] Рассмотреть запекание света для статической геометрии уровней.

## Публикация игры

- [ ] При публикации упаковывать `Content` в ZIP-архив с расширением `.pak`, сохраняя структуру папок. При загрузке открытый файл из `Content` имеет приоритет над одноимённым ресурсом в архиве. Вернуться к задаче при подготовке публикации тестовой игры.
