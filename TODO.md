# Задачи на будущее

## Виджет Text

- [ ] Добавить `FontSize` у виджета. Один растровый атлас должен работать с несколькими размерами текста. Измерение, перенос строк и выравнивание должны учитывать выбранный размер.
- [ ] Добавить начертания `Regular`, `Bold`, `Italic` и `BoldItalic` для всего виджета через отдельные TTF-файлы одной семьи.
- [ ] Добавить `AutoSize` с `MinFontSize` и `MaxFontSize`. Виджет выбирает самый крупный размер, при котором текст помещается в заданный `Rect` с учётом `WordWrap`. Если текст не помещается даже при минимальном размере, используется минимальный размер и обычное поведение `ClipToRect`.

## UI-атласы

- [ ] Добавить 9-slice для `Image` с областями атласа, чтобы при изменении `Rect` углы сохраняли размер, края растягивались вдоль своих осей, а центр заполнял оставшееся место.

## Звук и эффекты

- [ ] Добавить воспроизведение звука.
- [ ] Добавить систему частиц.

## Анимации

- [ ] Разобрать импорт из Blender и воспроизведение анимационных клипов. Анимации создаются в Blender.
- [ ] Отдельно рассмотреть скелетную анимацию и скиннинг, когда в игре появятся модели, которым они нужны.

## Освещение

- [ ] Рассмотреть динамические тени от направленных, точечных и прожекторных источников света.
- [ ] Рассмотреть запекание света для статической геометрии уровней.

## Публикация игры

- [ ] При публикации упаковывать `Content` в ZIP-архив с расширением `.pak`, сохраняя структуру папок. При загрузке открытый файл из `Content` имеет приоритет над одноимённым ресурсом в архиве. Вернуться к задаче при подготовке публикации тестовой игры.

## Привязка объектов

- [ ] Добавить Attach / Detach в редакторе и игре. Прикреплённая сущность следует за позицией и поворотом другого объекта, сохраняя собственный масштаб, поведение и коллайдер. Attach и Detach сохраняют мировое положение и поворот. При удалении объекта, к которому привязались, отсоединять сущности на месте. Запретить циклы и сохранять связь в .map по GUID. Примеры: кнопки на подвижной панели и свет на платформе. Физические соединения вне задачи.

## Твины

- [ ] Добавить TweenManager с обновлением из Game.Update. Поддержать интерполяцию чисел, Vector3 и Quaternion, easing, игровое и unscaled-время, отмену и обратный вызов при завершении. Первые примеры: появление UI-панели и движение объекта уровня.

## Игровая консоль

- [ ] Добавить отладочную консоль в игре. Открывать по тильде при IsDebug, показывать последние сообщения Log и выполнять зарегистрированные команды. Пока консоль открыта, блокировать управление персонажем.

## Виджет InputField

- [ ] Добавить однострочное поле ввода с фокусом, текстовым вводом через KeyChar, курсором, редактированием строки и событием Submitted по Enter. Вернуться к задаче, когда поле понадобится в настройках игры или для отладочной консоли.

## Расширения Lit-шаблона

- [ ] Добавить DeformVertex для изменения позиции и нормали вершины. Перенести существующую волну из Deform.vert как пример.
- [ ] Добавить ModifyBaseColor после чтения текстуры и до расчёта света. Проверить сочетание вершинной деформации с фрагментным эффектом GetEmission.

## Выгрузка ресурсов

- [ ] Добавить учёт использования ресурсов Content общей областью игры и областью уровня. При переходе освобождать ресурсы старого уровня, которые больше никому не нужны. Сохранять ресурсы нового уровня, общего UI и общие зависимости. Учитывать повторные запросы к кешу, загрузку во время игры и неудачный переход с сохранением старого мира. Для первой версии UI относится к общей области до закрытия приложения.
